# じゃんけんゲーム

ReactとTypeScriptで作られた、シンプルでモダンなじゃんけんゲームです。
ユーザーは「グー」「チョキ」「パー」を選択し、コンピューターと勝負することができます。

## ✨ 特徴

*   **直感的なプレイ**: アイコンをクリックするだけの簡単操作
*   **美しいデザイン**: グラデーション背景とスムーズなアニメーションを採用
*   **完全なレスポンシブ**: デスクトップでもモバイルでも快適にプレイ可能

## 🛠️ 使用技術

*   **React**: UIライブラリ
*   **TypeScript**: 型安全性のため
*   **Vite**: 高速なビルドツール

## 🚀 始め方

以下の手順で、ローカル環境でゲームを起動できます。

1.  **依存関係のインストール**
    ```bash
    npm install
    # または
    yarn install
    ```

2.  **開発サーバーの起動**
    ```bash
    npm run dev
    # または
    yarn dev
    ```

3.  **ブラウザで確認**
    ターミナルに表示されたURL（例: `http://localhost:5173`）にアクセスしてください。

## 🎮 遊び方

1.  画面に表示される「✊（グー）」「✌️（チョキ）」「✋（パー）」のいずれかのボタンをクリックします。
2.  コンピューターの手がランダムに選ばれ、勝敗が表示されます。
3.  「もう一度遊ぶ」ボタンを押すと、リセットされて再挑戦できます。
